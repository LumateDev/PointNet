# PointNet для классификации облаков точек (LiDAR)

Проект для сегментации и классификации облаков точек LiDAR с использованием архитектуры PointNet.

## 📋 Требования

- Python 3.8+
- CUDA (рекомендуется для GPU-ускорения)

## 🚀 Установка и настройка

1. **Создание виртуального окружения:**

   ```bash
   python -m venv poinnet_env
   source poinnet_env/bin/activate  # Linux/MacOS
   # или
   poinnet_env\Scripts\activate    # Windows
   ```

2. **Установка зависимостей:**

   ```bash
   pip install -r requirements.txt
   ```

3. **Подготовка данных:**
   - Скачайте датасет `Univer2019.las`
   - Поместите файл в корневую директорию проекта
   - Создайте версию без разметки и проверьте результат (подробнее см. ниже).

## 🔧 Использование

### Диагностика окружения и данных

1. Убедитесь, что датасет `Univer2019.las` находится в корневой папке репозитория (или передайте путь к файлу аргументом).
2. Запустите диагностику:

   ```bash
   python check_enviroment.py Univer2019.las
   ```

   Для быстрой проверки только окружения можно использовать флаг `--skip-data`:

   ```bash
   python check_enviroment.py --skip-data
   ```

Скрипт последовательно:

- сообщает версии Python и PyTorch, наличие CUDA/GPU и количество потоков CPU;
- анализирует структуру LAS-файла (диапазоны координат, список атрибутов, распределение классов);
- пробует загрузить сэмпл точек и преобразовать его в тензор PyTorch;
- предлагает стартовые параметры обучения (размер блока, батча и оценку требуемой памяти).

### Подготовка данных

Создайте версию датасета без меток (например, для псевдоразметки или инференса):

```bash
python create_unlabeled.py Univer2019.las unlabeled.las
```

После выполнения появится файл `unlabeled.las` в формате 1.2, содержащий только координаты точек. Скрипт проверяет существование исходного файла и сообщает об ошибках чтения/записи.

## 📁 Структура проекта

```

├── poinnet_env/          # Виртуальное окружение (в .gitignore)
├── Univer2019.las        # Исходный датасет (в .gitignore)

├── create_unlabeled.py   # Создание датасета без меток

```

## 📊 Датасет

- **Univer2019.las**: Исходный датасет с разметкой
- **unlabeled.las**: Версия без меток для инференса

## ⚠️ Важно

- Файлы `.las` добавлены в `.gitignore` из-за большого размера
- Для работы требуется скачать датасет отдельно
- Рекомендуется использовать GPU для обучения
