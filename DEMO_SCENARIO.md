# Сценарий демонстрации для преподавателя

Цель — показать готовность проекта к дальнейшему обучению модели: окружение проверяется, данные подготовлены, скрипты работают.

## 1. Подготовка окружения

```bash
python -m venv pointnet_env
source pointnet_env/bin/activate  # Windows: pointnet_env\Scripts\activate
pip install -r requirements.txt
```

## 2. Проверка наличия датасета

Убедитесь, что в корне репозитория лежит `Univer2019.las`. Если файл хранится в другом месте, укажите полный путь в командах ниже.

## 3. Диагностика окружения

```bash
python check_enviroment.py Univer2019.las
```

На демонстрации обратите внимание преподавателя на ключевые блоки вывода:

- наличие/отсутствие CUDA и параметры машины;
- структуру LAS-файла и распределение классов;
- успешную загрузку сэмпла точек и преобразование в тензор;
- предложенные параметры обучения.

### Быстрая проверка окружения без данных

```bash
python check_enviroment.py --skip-data
```

Команда полезна, если датасет ещё не скопирован на конкретную машину.

## 4. Подготовка версии без меток

```bash
python create_unlabeled.py Univer2019.las unlabeled.las
```

После выполнения должен появиться файл `unlabeled.las`. Покажите его размер и дату изменения (`ls -lh`) и подчеркните, что скрипт копирует только координаты.

## 5. Резервные шаги

Если требуется продемонстрировать устойчивость скриптов, можно запустить диагностику с несуществующим файлом:

```bash
python check_enviroment.py data/missing.las
```

Скрипт сообщит об отсутствии файла и корректно завершит работу без трассировки ошибок.

## 6. Следующие шаги

Завершите демонстрацию кратким планом дальнейших действий:

1. Реализация обучения модели PointNet.
2. Подготовка пайплайна для валидации и инференса.
3. Добавление визуализации результатов классификации.
